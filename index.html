Metodologi Deteksi Anomali (Z-Score)

Sistem menggabungkan Rule-Based Thresholding dan Z-Score (Standard Score) untuk membedakan pemakaian normal vs anomali lonjakan data tidak wajar.

Rumus Z-Score:
Z = (X - μ) / σ
  • • X: Nilai trafik real-time saat ini
  • • μ (Mean): Rata-rata historis metrik
  • • σ (Std Dev): Standar deviasi data
Kriteria Ambang Batas (Rule):
|Z| ≤ 1.5 Normal
1.5 < |Z| ≤ 2.5 Warning
|Z| > 2.5 Anomali / Kritis
Keunggulan Metode:

Meminimalkan False Alarm saat jam sibuk wajar, namun sigap mendeteksi lonjakan mendadak seperti serangan DDoS atau kabel jaringan rusak.

Masalah Utama

Gangguan jaringan sulit diketahui sebelum banyak pengguna terdampak (Reaktif vs Proaktif).

Tujuan Sistem

Membangun Early Warning System untuk mendeteksi anomali performa secara otomatis & instan.

Metodologi & Algoritma

Menggunakan kombinasi Rule-Based Thresholding dan Anomaly Detection (Z-Score). Pilihan ini efisien untuk memproses data streaming tanpa beban komputasi berat serta akurat membedakan lonjakan trafik wajar vs gangguan kritis.
